# Tinotenda Muzambi

I build web products and applied data systems, with a focus on software that is
useful, explainable, and straightforward to operate.

My work spans full-stack TypeScript, Python, R, and data science. Recent projects
include production Next.js applications and research into music recommendation
with path signatures.

## Selected work

- [Music recommendation with path signatures](https://github.com/TinoMuzambi/MusicRecPathSignatures)
  — a reproducible research pipeline with baselines, statistical evaluation,
  robustness analysis, and an extensive automated test suite.
- [ReComments](https://github.com/TinoMuzambi/ReComments) — an independent
  discussion layer for YouTube videos with comments disabled.
- [Paystack integration demo](https://github.com/TinoMuzambi/Paystack) — a
  typed Next.js reference implementation for Paystack payment flows.
- [Project archive](https://projects.tinomuzambi.com) — case studies and source
  links for work across web engineering, data, and mobile development.
